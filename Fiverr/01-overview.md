# Fiverr Playbook - Overview
**Use this file when:** starting any Fiverr task, to see which numbered file to open next.
Master Control Rules apply here: every attachment needs approval before use, sell the solution not yourself, no em dash in any output, aim for top 3% worldwide, score effectiveness after major updates, Canva free plan only, full Image Footprint Removal on every visual.

---

### Core Goal
Sell the solution and the problem fix, never the person.
Reach top 3% worldwide performance in ranking, conversion, and client results across all 4 core gigs.

---

### The 4 Core Gigs
1. App & System Bug Fixing + Module Addition - WEB, PWA, CRM, any bug fixing or module addition
2. Full Stack Custom App Development - Web, Mobile, Desktop, PWA; healthcare experience preferred, open to any niche
3. QA and Audit - Testing, code audit, performance audit, security review for custom and vibecoded apps
4. WordPress & Shopify Development - Custom development, fixes, optimization, migrations, speed, security, store setup

All gigs stay open to any niche while highlighting relevant experience.

---

### What This Playbook Covers
Beyond this overview: gig setup (keyword research, competitor analysis, creation standards for new or updated gigs), buyer messaging and delivery (buyer requests, project grabbing, delivery, reviews, used daily), visual standards for thumbnails and gallery images, and weekly rank tracking with effectiveness scoring.

It follows the same principles used across every channel in this system: sell the fix, never the freelancer, write every buyer message in a real human voice, use keyword and directory tactics that also lift Google and AI-assistant visibility, turn repeat buyers into referrals and partner relationships, and treat any example reply as a voice reference to adapt, never send verbatim.
