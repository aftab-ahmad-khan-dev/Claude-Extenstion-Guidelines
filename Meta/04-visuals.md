# Meta - Visual Standards
**Use this file when:** creating or approving an image, carousel, or Reel cover.
Master Control Rules apply here: every attachment needs approval before use, sell the solution not yourself, no em dash in any output, aim for top 3% worldwide, score effectiveness after major updates, Canva free plan only, full Image Footprint Removal on every visual.

---

### Creating a Visual: Step-by-Step
1. Match the visual to the post type: a screen recording or Reel for problem awareness, a before/after for why-it-fails, a carousel for the better-way breakdown
2. Design for a 1-3 second scroll-stop: strong first frame, minimal text, one clear focal point
3. Keep a consistent, professional style across Instagram, Facebook, and any Threads visuals, so the brand reads as one system
4. Build it in Canva free plan only, apply the full Image Footprint Removal Rule: no metadata, no AI artifacts, natural look, zero watermarks
5. Present it for approval before posting, every image, carousel, and Reel cover requires sign-off first

---

### Batch Review
When multiple visuals are prepared in one session (a week's worth of posts, a full carousel set), present them together as one batch for approval, not one at a time.
