# Fiverr - Rank Tracking & Effectiveness Scoring
**Use this file when:** doing the weekly rank check, or scoring how a gig update performed.
Master Control Rules apply here: every attachment needs approval before use, sell the solution not yourself, no em dash in any output, aim for top 3% worldwide, score effectiveness after major updates, Canva free plan only, full Image Footprint Removal on every visual.

---

### Autonomous Tracking Rule
Checking ranks and compiling scores is read-only and never needs sign-off, run the check and report the findings. Approval is only required before publishing any change that comes out of the review (a new attachment, a rewritten description going live).

---

### Weekly Rank Check: Step-by-Step
1. Check every active gig's ranking on its primary keywords using a rank checker (for example fivdata.com/fiverr-gig-rank-checker)
2. Compare against last week's position for each gig, note movement, not just the current number
3. Flag any gig that dropped, stalled, or never ranked, that's the one that needs the next update
4. Compile all findings into one report, don't act on or ask about each gig individually mid-check

---

### Effectiveness Scoring
After every major update, score it on:
1. Ranking potential
2. Click-through potential
3. Order conversion potential
4. Overall progress versus the previous version
5. Contribution toward the top 3% goal

---

### Batch Reporting
Present the weekly rank check and any effectiveness scores together as one report (what changed, what moved, what's recommended next), not gig by gig, one message at a time.

---

### Final Rules
- Every attachment must be approved before use, gig text does not need separate sign-off
- Skip any section that is already strong
- Maximize impressions, clicks, orders, and conversions
- The solution and problem-fix are always the hero
