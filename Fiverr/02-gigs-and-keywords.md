# Fiverr - Gigs, Keywords & Competitor Research
**Use this file when:** creating a new gig or refreshing an existing one's keywords, title, packages, or description.
Master Control Rules apply here: every attachment needs approval before use, sell the solution not yourself, no em dash in any output, aim for top 3% worldwide, score effectiveness after major updates, Canva free plan only, full Image Footprint Removal on every visual.

---

### Autonomous Drafting Rule
Gig copy (title, description, tags, package text) never needs sign-off before publishing, draft and update it using this file. Only the visual assets (thumbnail, gallery images) require approval before use, per Master Control Rules.

---

### Keyword Research: Step-by-Step
1. Pull candidate keywords from Fiverr autocomplete, a rank checker, Reddit, Quora, and real buyer language, not guesses
2. Prioritize low-saturation keywords, target under roughly 3k competing gigs where realistically possible
3. Rank candidates by how closely they match a real, specific buyer problem, not by search volume alone
4. Pick one primary keyword per gig and 2-3 supporting ones, spread thin across too many keywords dilutes ranking
5. Revisit and refresh titles, tags, and descriptions on a schedule (monthly at minimum) based on new data, never set once and forget

Goal: page 1, row 1 ranking on strong commercial keywords.

---

### Competitor Analysis: Step-by-Step
1. Pull the top 3-4 highest performing gigs for each target keyword
2. Break down what's actually working: title structure, thumbnail style, package tiers, description structure, tags
3. Identify the gap, what's missing, generic, or weak across all of them
4. Build a version that's cleaner, more precise, and fills that gap, never a copy with words swapped

---

### Gig Creation Standards
1. Every description follows Pain to Solution structure: the real problem first, then the fix, never features first
2. Strong titles lead with the best low-saturation keyword as close to the front as natural phrasing allows
3. Basic / Standard / Premium packages are clearly differentiated by real scope, not just price
4. Only high-potential tags, each one earning its place, not filled just to use the slot count

---

### Batch Review
When multiple gigs are being created or refreshed in one session, draft all the copy first, then group it into one batch (gig name, what changed, why) for a single review pass, not gig by gig.
