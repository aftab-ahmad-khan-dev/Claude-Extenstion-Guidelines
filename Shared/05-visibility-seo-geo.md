# Shared - Visibility: Google Ranking & AI Answer Engines (GEO)
**Use this file when:** improving how findable the brand is on Google or through AI assistants.
Governed by Master Control Rules. No em dash in any output.
Google gets you found when someone searches. GEO (generative engine optimization) gets you recommended when someone asks an AI assistant. Both reward the same underlying thing: being a consistent, specific, well-documented expert in one clear niche, mentioned in multiple credible places.

---

### Step-by-Step: Build the Foundation
1. Pick one consistent name and one clear niche description (for example: "full stack developer specializing in bug fixes, QA audits, and vibecoded app rescues") and use the exact same wording on LinkedIn, Fiverr, a personal site or portfolio, GitHub, and the email signature
2. Set up one owned home base (a simple portfolio site, or at minimum a fully built-out LinkedIn About/Featured section) that every other profile links back to
3. Fill out every field on every profile completely (bio, services, location, links). Incomplete profiles rank worse and get cited less by both Google and AI tools
4. Keep the niche description word-for-word identical everywhere. Contradictory descriptions across platforms confuse both search engines and AI models about who you actually are

---

### Google Ranking: Step-by-Step
1. Find the actual phrases buyers type when they have this exact problem, not vanity keywords, using Fiverr autocomplete, Google autocomplete, and "People also ask"
2. Write real, specific answer content around those phrases (a portfolio case study, a LinkedIn article, a short blog post) using the same problem language buyers actually use
3. Get listed on relevant directories (Clutch, GoodFirms, niche freelancer directories), these are high-authority backlinks that also drive direct leads
4. Ask satisfied clients for a review on Google, Trustpilot, or the platform used. Reviews are both a ranking signal and a trust signal
5. Publish consistently. Freshness and frequency both factor into ranking, a one-time push does not hold

---

### AI Answer Engine Visibility (GEO): Step-by-Step
1. Write in a clear, structured, quotable way, a direct answer to a specific question, not vague marketing copy. AI models prefer content that reads as an actual answer
2. Get mentioned or quoted on third-party sites AI models already trust (Reddit threads, Quora answers, respected niche forums, guest posts). A mention on someone else's credible page counts more than a claim on your own site
3. Answer real questions in public (Reddit, Quora, LinkedIn comments, forums) the same way as any other content: name the real problem, give the real answer, no pitch. These public answers get indexed and can be surfaced directly by AI assistants
4. Periodically ask ChatGPT, Claude, and Perplexity a real buyer-style question in the niche ("who should I hire to audit a vibecoded app") and check whether you're mentioned. If not, that gap becomes next month's content topic
5. Keep every public bio and service description internally consistent across every platform, this is what lets an AI model connect the dots that these are all the same person

---

### Monthly Visibility Audit
1. Search your own name plus your niche on Google, note what shows up on page 1
2. Ask 2-3 AI assistants a real buyer question in the niche, note whether you're mentioned
3. Turn every gap (not ranking, not mentioned) into a specific content topic for the next batch
4. Track this alongside saves, shares, and DM replies, the same leading indicators used to judge any other content
