# LinkedIn - Profile Optimization
**Use this file when:** rewriting or auditing any section of the LinkedIn profile.
Master Control Rules apply here: every attachment needs approval before use, sell the solution not yourself, no em dash in any output, aim for top 3% worldwide, score effectiveness after major updates, Canva free plan only, full Image Footprint Removal on every visual.

---

### Autonomous Drafting Rule
Profile text (headline, about, experience, services) never needs sign-off before drafting, write it using this file. Only the banner image and any Featured graphics require approval before use, per Master Control Rules.

---

### Profile Audit: Step-by-Step
1. Read every section as a stranger would, note anywhere it talks about you instead of the problems you solve
2. Rewrite each weak section using the standard for that section below
3. Keep the same name, niche, and service description word-for-word consistent with every other platform, so both people and AI assistants connect the dots that it's the same expert
4. Draft every section that needs a rewrite in one pass, present the full set together for one review, not section by section

---

### Section Standards
- Headline: Focus on the outcome and the type of problems solved, not a job title
- About: Start with the common pain, explain why generic approaches fail, position precise custom remote solutions as the better path, end with a calm invitation, never a hard pitch
- Featured: Pin the strongest problem-solution posts and process posts, swap out anything that's stopped performing
- Experience: Rewrite to highlight problems solved and outcomes delivered, not a list of responsibilities
- Services & Open to Work: Set to Remote + Worldwide, list clear, solution-focused services matching the 4 core gigs
- Banner: Clean and solution-oriented, requires approval before use like any other visual

---

### Batch Review
When multiple sections are being rewritten in one pass, present the full set together (section, old text, new text) for one review, not one section at a time.
